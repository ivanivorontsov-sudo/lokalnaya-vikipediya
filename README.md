# Локальная Википедия (ru.vorontsov.wiki)

Офлайн-читалка русской Википедии (база `ruwiki.db`). Исходники восстановлены из APK 1.1 (jadx), т.к. оригинальный проект на сервере не сохранился.

## 1.2 (versionCode 3)
- Исправлено: после удаления шаблонов (транскрипция, ударение, этимология, языки) в тексте оставались пустые скобки «Сердце (,) — …».
- Новый `TextClean`: убирает скобки только из знаков препинания/пробелов (в т.ч. вложенные), скобки только с языковыми пометками без слова («(лат. ; )»), лишние запятые в начале/конце скобок, двойные пробелы и пробел перед знаками препинания. Применяется к тексту статьи и к выдержке в выдаче.
- Тесты: `java -cp . TextCleanTest` (см. tools/test.sh).

Сборка 1.2 сделана подменой изменённых классов (javac + d8 → smali) в исходном APK, т.к. часть декомпилированного `SearchCore` не компилируется как есть. Подпись — тот же ключ, что и у 1.1 (ставится поверх). Ключи в репозитории не хранятся.

Заимствовано: jadx, dex2jar/smali (сборка), Snowball stemmer (уже был в приложении).

## 1.2.1 (versionCode 4) — исправление 1.2
- В 1.2 MainActivity/ArticleActivity были пересобраны из декомпилированного (jadx) кода — это ломало поиск («Ищу…») и открытие статей. 1.2.1 собрана иначе: весь код 1.1 оставлен байт-в-байт, в ArticleActivity (фоновый поток загрузки статьи) добавлены только 2 инструкции вызова `TextClean.text` (patches/ArticleActivity.smali.diff). Выдача поиска не трогается.
- `TextClean` переписан без регулярных выражений: один проход, O(n); 1 МБ — ~44 мс, все 541 статьи тестовой базы — ~0.3 с; при любой ошибке возвращает исходный текст.
- Сборка: baksmali 1.1 → патч → smali, версия через apktool, подпись тем же debug-ключом.
